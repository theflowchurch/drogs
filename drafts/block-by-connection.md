# Idea on hold (office, 24 Nov): block blocked people by internet connection

Not built. The office will say if it wants it.

- When a blocked person is caught, also save the internet address (IP) they used;
  any device on that connection then sees only "Service Unavailable".
- Admin › Settings lists blocked connections (when, why) with an Unblock button.
- Safeguards: blocks expire after 30 days unless renewed; never block a connection a
  member in good standing has used.
- Risks: shared connections (church/office Wi-Fi, mobile networks) block innocent
  people; addresses change; a VPN or switching to mobile data gets round it.
